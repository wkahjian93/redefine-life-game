# REDEFINE Life Game

A mobile-first, offline money game played with a licensed insurance agent (REDEFINE). Education only, not financial advice.

- **Quick Mode** (60–90 s): Guess the Price → money personality card → player WhatsApps the agent.
- **Full Mode** (10–15 min): dreams, life stages, life cards → scorecard, before vs after, one-page needs summary.

Live app: https://wkahjian93.github.io/redefine-life-game/ · Agent guide: [HOW TO USE.md](HOW%20TO%20USE.md) · Figures and sources: `docs/data.js` (also on the in-app Sources screen).

Develop: `node tools/serve.js` (port 5199) · tests: `node test.js`. After changing files in `docs/`, bump `VERSION` in `docs/sw.js`.
